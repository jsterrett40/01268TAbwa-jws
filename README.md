# Aether Wing IV

A real-time, explorable model of the solar system that runs in the browser. Best on a tablet or a computer with a recent browser; it takes a few seconds to load.

**Controls**
- Touch: drag to orbit, pinch to zoom, tap a body to fly to it. Use the buttons along the bottom for speed, pause, Clockwork view and more, and the list on the right to pick a destination.
- Mouse and keyboard: drag to orbit, scroll to zoom, click a body, `[` `]` speed, `Space` pause, `C` clockwork view, `N` destination list, `L` labels, `O` orbit lines, `S` screensaver.
